# ✊✋✌️ Rock Paper Scissors

A console-based Rock Paper Scissors game built with JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. You play 5 rounds against the computer, and the winner is announced at the end.

## How to Play

1. Open `index.html` in your browser.
2. Open the developer console (`F12` → **Console**).
3. A prompt appears each round: type `rock`, `paper` or `scissors` (any letter case works).
4. Watch the round results, the running score and the final winner in the console.

To play again, refresh the page.

## Features

- Random computer choice with `Math.random()`
- Case-insensitive player input
- Round results with the winner announcement (e.g. `You win! Rock beats Scissors`)
- Score tracking over 5 rounds and a final result (win, lose or tie)
